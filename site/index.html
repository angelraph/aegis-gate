Two strangers can trade privately without trusting each other.

Aegis Gate is escrow for shielded Zcash. The buyer pays into a shielded address that three people control together. Any two of them can move the money. No one alone can, Aegis included.

A deal, start to finish

How a trade runs

  1. Seller opens a deal

    Item, price in ZEC, terms. Aegis Gate gives a link to send over Signal, Telegram or a DM. No accounts.

  2. Three keys are made

    Buyer, seller and arbiter run FROST key generation. Each keeps one share. The escrow address comes out of it.

  3. Everyone checks the escrow

    Each side recomputes the address from the shared group key and the deal ID. If anything differs, the deal stops.

  4. Buyer pays in

    From Zashi, Zodl or any Ironwood wallet. Both sides see "funded" through the viewing key. Nothing about the deal is visible on-chain.

  5. Two keys release it

    Buyer and seller co-sign the payout. In a dispute, the arbiter co-signs with whoever is right.

From working core to product

Browser signer

Each key share lives only in its owner's browser. Before signing, it shows "pay X ZEC to Y" and refuses anything else. Never a bare hash.

Deal links

Create, join, fund with a QR code from your wallet, release or refund with one button. An arbiter dashboard handles disputes.

First purchase as onboarding

New users set up a wallet, get ZEC and shield it inside the deal, so their first shielded transaction buys something real.

Mainnet deals

Small real trades with the community, each auditable through its escrow viewing key.
